# File manager interaction map

Pointer: the dock or launcher opens the file manager; a selected location is
passed as a desktop-entry argument under the existing user session. Keyboard:
launcher search, Enter to open, Escape to cancel, and standard file-manager
navigation belongs to Nautilus. Focus must remain in the file manager after
launch. If the entry is missing or activation fails, show an actionable error
without retry loops or hidden command execution.
