# Interaction interpretation

PROPOSED Axiom mapping: pointer and keyboard reach equivalent named actions;
focus stays visible; a targeted window remains the target through the request;
Escape dismisses reversible overlays. Dock application activation resolves an
actual app/window instead of animating a sample card. State updates come from
the backend, and in-progress/failed operations remain distinguishable.

These are Axiom decisions informed by [public references](evidence.md), not a
measured recording of macOS input. Shortcut choices and accessibility behavior
must be validated on Linux rather than copied from Apple's modifier layout.
