# Implementation research boundary

Use [window foundation source findings](../window-foundation/linux-references.md)
for Linux implementation. Quickshell's native models replace any need to infer
Apple internals. Installed desktop entries and icons will supply Dock identity.

Later investigations must inspect the relevant Linux source/protocol before
writing a feature specification. Protocol compatibility, capture availability,
application identity and multi-monitor behavior cannot be established by a
macOS video, screenshot or HIG paragraph.
