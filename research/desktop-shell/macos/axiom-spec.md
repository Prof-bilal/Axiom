# Axiom interpretation of the reference

Reference: [public Apple sources](evidence.md).

Evidence: documentation supports studying clear app/window distinctions and
precise interaction feedback; it supplies no runtime measurements here.

Linux implementation: native compositor models, desktop entries, real service
APIs and keyboard-accessible QML surfaces.

Axiom decision: adopt discoverability and consistent, responsive actions as
goals. Use Axiom graphite/teal tokens and existing penguin/wordmark artwork;
application icons come from installed applications. Central reduced-motion and
focus policies apply to every feature.

Reason: the desktop must be coherent and operable in the actual Linux session.

Difference: preserve Hyprland workspaces/tiling, Linux service authority and
application lifetime; no pixel-perfect Apple clone or copied system resources.
