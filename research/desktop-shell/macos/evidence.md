# Public macOS evidence

Accessed 2026-10-28; DOCUMENTED, not runtime-observed. No Mac is available.

| Source | Observed public contract |
| --- | --- |
| [Dock user guide](https://support.apple.com/guide/mac-help/open-apps-from-the-dock-mh35859/mac) | Launch from icons; contextual actions; pin/remove/reorder; configurable placement/hiding; keyboard traversal and badges |
| [Window user guide](https://support.apple.com/guide/mac-help/work-with-app-windows-mchlp2469/mac) | Close, minimize and fill/restore are separate actions; application switching differs from individual window management |
| [HIG Windows](https://developer.apple.com/design/human-interface-guidelines/windows) | Distinguishes primary/auxiliary windows and advises adaptable, familiar window behavior |
| [HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion) | Purposeful, brief, optional and cancellable animation; avoid needless motion on frequent interactions |

HIG HTML initially required JavaScript. The official linked `.md` endpoints were
retrieved successfully with curl. No Apple images, icons, fonts or wallpapers
were downloaded. Guides can change by OS version; do not infer an exact release's
timing or implementation from the current public page.
