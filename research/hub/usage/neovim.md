# Neovim
## When to use
- You already know Vim and want a modern, extensible version of it.
- You work in a terminal, including over SSH, with minimal GUI overhead.
- You want built-in LSP support and Tree-sitter parsing.
- You want to script the editor in Lua.
## How it works
- Vim's modal editing applies: normal mode for commands, insert mode for typing, visual mode for selections.
- Built-in `:terminal` and multicursor editing are available.
- Configuration lives in `init.lua`; Lua is built in, and Vimscript is still supported.
- Learn with `:Tutor` and the `:help` system; move from Vim with `:help nvim-from-vim`.
## Not for
- Users who want a conventional GUI editor with no modal learning curve; use VS Code or Zed.
- Teams needing a turnkey IDE for Java or Android; use IntelliJ IDEA or Android Studio.
