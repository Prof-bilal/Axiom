# DB Browser for SQLite

## When to use
- You have a SQLite file and want to inspect or fix its contents without writing SQL.
- You need to create, modify, or delete tables and indexes visually.
- You want to import a CSV into a SQLite table or export a table to CSV or an SQL dump.
- You need to add, change, or remove SQLCipher encryption on a database file.

## How it works
- Open a SQLite or SQLCipher file; tables appear as a spreadsheet-like view.
- Add, edit, delete, sort, and search records directly in that view.
- Write SQL queries to run them and inspect the results.
- Structure changes (tables, indexes) are made through dialogs; plain graphs can be plotted from query results.

## Not for
- Client/server databases such as PostgreSQL or MySQL; use pgAdmin, DBeaver, or TablePlus.
- Relying on nightly builds: the project warns they are "not warranted to be reliable".
