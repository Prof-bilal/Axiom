# Cemu

## When to use
- You want to play Wii U games on a PC.
- You are an enthusiast tracking emulation compatibility for Wii U titles.
- You have a GPU with OpenGL 4.5 or Vulkan 1.2 and at least 4 GB of RAM.
- You want to check a title's status on the project's compatibility database before playing.

## How it works
- A C++ Wii U emulator from the Cemu project.
- Official downloads and release notes are on GitHub (v2.6 is the current release on the official site).
- Graphics: Vulkan is preferred; GPUs with less than 2 GB of video memory should use OpenGL.
- Linux availability is listed on Flathub (`info.cemu.Cemu`); the official site documents Windows setup.

## Not for
- Machines below the stated minimums (4 GB RAM, OpenGL 4.5 or Vulkan 1.2).
- Anyone expecting a documented Linux install path on the official site; the Linux steps are not on it.
