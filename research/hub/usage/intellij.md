# IntelliJ IDEA Community
## When to use
- You write Java or Kotlin applications and want a full JVM IDE for free.
- You want a project model that understands Gradle or Maven projects.
- You want code editing with coding assistance and refactoring.
- You want to add plugins to extend the IDE.
## How it works
- Open or create a project, then configure the project model.
- Write code in the editor with coding assistance and learn the keyboard shortcuts.
- Create, run, and package a simple Java or Kotlin application from the IDE.
- Tool windows, debugger, and VCS details: Not found in the official pages reviewed.
## Not for
- Android-specific tooling such as emulators and Android profilers; use Android Studio.
- Lightweight, multi-language editing in a fast editor; use VS Code or Zed.
