# Lutris

## When to use
- You have games spread across several stores and launchers (Steam, GOG, Epic, Battle.net, Humble Bundle) and want one library.
- You want to run Windows games through Wine, or run classic games through emulators, from the same interface.
- You need to add a game you installed yourself, by pointing Lutris at its executable.
- You want community install scripts to set up a difficult game.

## How it works
- The library lists your games; each game is tied to a runner, the program that runs it.
- Runners include Wine-based compatibility layers, emulators, and engine re-implementations; Linux-native games use the Linux runner.
- Runners are installed and managed from Manage Runners (Tools menu in recent versions).
- Adding a game uses the + button; for a locally installed game, pick the runner first, then the executable.
- Install scripts automate downloads and setup for many titles.

## Not for
- Running one Windows game with fine Wine prefix control; use Bottles.
- Playing only Steam titles; use Steam directly.
