# Plex Media Server

## When to use
- You keep your own video, music and photo library on a machine or NAS and want to stream it to TVs, phones and browsers.
- You want automatic metadata and artwork for a personal media collection.
- You have several household devices that need the same library.
- You want a server you can run on Linux with the official packages.

## How it works
- The server indexes your media folders and streams them to Plex apps; the server download is free.
- Official Linux packages (per search results, not confirmed on a fetched page): Ubuntu, Debian, CentOS, Fedora and SUSE.
- The Plex desktop client for Linux is distributed through Snapcraft and Flathub, not the server download page.
- Proprietary software; Plex trademarks need written permission to reuse.

## Not for
- Fully offline or self-hosted-only setups with no account: Plex sign-in is part of the normal setup.
- Users who need open-source streaming software; Plex Media Server is closed-source.
