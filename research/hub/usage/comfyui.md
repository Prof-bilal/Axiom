# ComfyUI

## When to use
- You want to build image, video, audio or 3D generation pipelines by connecting nodes.
- You need fine control over diffusion model steps instead of a one-prompt interface.
- You want to run open-source generative models on your own GPU.
- You are a designer or developer experimenting with reusable generation workflows.

## How it works
- A node-based graphical interface and backend for diffusion models (GPL-3.0, by Comfy Org).
- Each workflow is a graph of nodes; you wire inputs, models and outputs together.
- Runs locally on Linux, Windows and macOS, or through a cloud service or API.
- Linux users can use the Comfy Desktop .deb or AppImage, or install from the source repository.

## Not for
- Machines with no suitable GPU; the official docs call for a GPU and a recent PyTorch build.
- Users who want a simple prompt box with no workflow editing.
