# Kate
## When to use
- You use KDE and want a capable, native text editor and lightweight IDE.
- You work on a project folder and want a project sidebar with search and replace across it.
- You want split views and tabs to work on several files at once.
- You want an embedded terminal and one-click project builds.
## How it works
- Open files in tabs; split the view to work on files side by side.
- The project sidebar shows the directory tree; search and replace works across the whole project.
- Plugins provide the integrated terminal, GDB debugging, SQL queries, and builds.
- LSP provides autocompletion for many languages.
- Sessions: Not found on the official page reviewed.
## Not for
- Heavy JVM or Android development; use IntelliJ IDEA or Android Studio.
- Terminal-only work over SSH; use Neovim or Helix.
