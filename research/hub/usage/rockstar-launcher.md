# Rockstar Games Launcher

## When to use
- You own Rockstar PC titles (such as GTA V or Red Dead Redemption 2) bought from Rockstar's store and want to launch them on Linux.
- You need the Rockstar Social Club account tied to your Rockstar games.
- You are already using Lutris to manage Windows games under Wine.

## How it works
- Rockstar's proprietary Windows client, freeware, for downloading and launching Rockstar PC titles.
- On Linux, it is usually run through Lutris with a Wine runner.
- The Lutris entry installs an older launcher build; the current official launcher may not install.
- Community reports say the install script was removed for some titles, so a manual install may be needed.

## Not for
- Rockstar's current official launcher as a guaranteed install path on Linux; this is not verified.
- Native Linux support; Rockstar does not publish a Linux build.
