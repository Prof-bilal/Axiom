# Goose
## When to use
- You want a general-purpose agent on your own machine, not only for coding.
- You want to choose your own LLM provider, using API keys or existing subscriptions.
- You want reusable workflows packaged as recipes that can run in CI.
- You want to add tools through MCP-based extensions.
## How it works
- Available as a desktop app, a CLI, and an API.
- Extensions give the agent MCP-based tools and data connections; 70+ are documented.
- Providers are the LLM backends (for example Anthropic, OpenAI, Google, Ollama).
- Recipes are portable YAML workflows with instructions, extensions, and parameters.
- Sessions and a typical task flow: Not found on the pages I could read.
## Not for
- Users who only want an editor-integrated coding assistant; use VS Code or Zed with an agent.
- Users who want a single fixed provider and no configuration; use Claude Code or Codex.
