# Lapce
## When to use
- You want a fast, native Rust editor with GPU-accelerated rendering.
- You want built-in Vim-style modal editing without a plugin.
- You want built-in LSP and Tree-sitter highlighting with no extra setup.
- You need to work on a remote machine with a local-like experience.
## How it works
- It is a native GUI editor from the Lapdev team, built on the Floem UI library.
- Built-in LSP provides completion, diagnostics, and code actions.
- Plugins can be written in any language that compiles to WASI.
- Panels, palette, and settings file location: Not found in the docs index I could read.
## Not for
- Users who need a large mature plugin ecosystem; use VS Code.
- Terminal-only environments; use Neovim or Helix.
