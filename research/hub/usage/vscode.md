# Visual Studio Code
## When to use
- You want a general-purpose editor with a large extension ecosystem for almost any language.
- You work across a project folder with an explorer, search, and integrated terminal in one window.
- You want built-in debugging with a Run and Debug view.
- You want AI chat in the secondary side bar alongside your code.
## How it works
- The Activity Bar switches views; the Primary Side Bar holds the Explorer; the Editor can be split side by side.
- The Panel below the editor shows output, problems, debug information, and the integrated terminal.
- The Command Palette (Ctrl+Shift+P / Cmd+Shift+P) runs any command; Quick Open (Ctrl+P) finds files by name.
- Typical flow: open a folder, edit files from the Explorer, run commands in the integrated terminal, debug from the Run and Debug view.
## Not for
- Heavy JVM or Android work where a full IDE with deep build tooling is better; use Android Studio or IntelliJ IDEA.
- Users who need a telemetry-free build; use VSCodium.
