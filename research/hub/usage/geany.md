# Geany
## When to use
- You want a small, fast GTK editor with few dependencies.
- You are not on KDE or GNOME and want a lightweight IDE.
- You need a symbol list and document list in a sidebar while you code.
- You want to open files quickly from the command line.
## How it works
- Each open file is a document shown in an editor tab.
- The sidebar has a Symbols view (code symbols) and a Documents view (open files).
- Open with File > Open or `geany file:line:col` to jump to a position.
- Build menu and plugin setup: Not found in the sections I could read.
## Not for
- Java or Android projects that need deep build and refactoring tools; use IntelliJ IDEA or Android Studio.
- Users who want modal editing; use Neovim or Helix.
