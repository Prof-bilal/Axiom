# Sublime Text
## When to use
- You want a fast, lightweight editor for large files and quick navigation.
- You edit with multiple selections and column selection often.
- You organize work as projects defined in a `.sublime-project` file.
- You want to run builds from a build system defined in the project or settings.
## How it works
- A project file (`.sublime-project`, JSON) lists folders, project settings, and inline build systems.
- A `.sublime-workspace` file stores per-user state such as open files; it is not usually version controlled.
- Build systems appear under Tools > Build Systems.
- Command palette and Goto Anything (Ctrl+P): Not found on the pages I could read.
## Not for
- Users who need an integrated debugger and full IDE features; use VS Code or IntelliJ IDEA.
- Teams that want a fully open-source editor; Sublime Text is proprietary.
