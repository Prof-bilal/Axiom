# VSCodium
## When to use
- You want VS Code's editor experience without Microsoft's telemetry and tracking.
- You want a freely licensed (MIT) build of the editor for a privacy-sensitive setup.
- You want to keep the same workflow and keybindings as VS Code.
## How it works
- VSCodium is a community build of Microsoft's VS Code source, compiled from the clean source tree.
- Telemetry is disabled by default, and Microsoft-specific gallery and telemetry endpoints are not configured.
- The editor UI, Command Palette, Explorer, and integrated terminal work as in VS Code.
- Extensions: the project documentation covers how the extension marketplace is handled; Not found in the official page reviewed.
## Not for
- Tasks that depend on Microsoft-only extensions or the official Marketplace; check extension availability first.
- Users who need Microsoft's official builds and support; use VS Code.
