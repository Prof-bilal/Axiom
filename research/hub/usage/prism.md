# Prism Launcher

## When to use
- You play Minecraft with several separate setups and want each kept apart.
- You want to install or update individual mods from Modrinth or CurseForge.
- You want to install, launch and update modpacks without doing each step by hand.
- You switch between multiple Minecraft accounts.

## How it works
- An instance is a separate Minecraft setup with its own settings, mods and configuration; you switch between instances.
- Mods are added to an instance and can be downloaded and updated through Modrinth and CurseForge.
- Modpacks are installed and kept up to date from inside the launcher.
- Accounts are managed inside the launcher alongside instances.

## Not for
- Installing games from store launchers such as Steam, Epic or GOG; use Steam, Heroic or Lutris.
- Non-Minecraft games; it is built only for Minecraft.
