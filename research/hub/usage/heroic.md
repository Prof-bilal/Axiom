# Heroic Games Launcher

## When to use
- You own games on the Epic Games Store, GOG or Amazon Prime Gaming and want to play them on Linux.
- You want one library for those three stores, with downloads and launches from a single app.
- You want to run Windows store games through Wine or Proton, with the Proton or Wine version chosen per game.
- You want to add a non-store game or launcher, such as EA App or Ubisoft Connect, from inside Heroic.

## How it works
- Sign in to each store from the login screen; your library then appears in one place.
- The Library lists games; downloads and launches happen from there.
- Each game can use a chosen Wine or Proton version; custom versions can be downloaded from within Heroic.
- The Add Games button adds an executable as a custom game; save syncing covers Epic and GOG games.
- ProtonDB compatibility info is searchable inside the app.

## Not for
- Steam-owned games; use Steam directly.
- Emulators and games from many other sources in one place; use Lutris.
