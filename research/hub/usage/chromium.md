# Chromium

## When to use
- You want an open-source, Google-maintained browser without Google's proprietary additions.
- You are testing web pages against the engine that powers Chrome, Edge, and Opera.
- You are contributing to or building a browser from the Chromium source.
- You need a browser whose source you can inspect and modify under its open licences.

## How it works
- Chromium is the open-source project that Google Chrome, Microsoft Edge, Samsung Internet, and Opera are built on.
- Google's own components are added to Chrome, which is proprietary; Chromium itself is open source.
- The Google-authored code is under BSD, and other parts use MIT, LGPL, MPL, and similar licences.
- The chromium.org site is aimed at contributors: discussions, bug filing, testing Beta, Dev, or trunk builds, and submitting patches.

## Not for
- A supported, stable end-user browser: the sources say Google does not provide an official stable build, and all releases are developmental.
- Users who want the Chrome build with Google's services and proprietary components; use Google Chrome instead.
