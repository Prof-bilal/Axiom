# DBeaver Community

## When to use
- You need one free, open-source GUI for many SQL databases (PostgreSQL, MySQL, SQLite, SQL Server, and others).
- You want to draw ER diagrams of an existing schema.
- You need to import, export, or move data between databases and file formats such as CSV, JSON, or XLSX.
- You want a multi-platform tool that runs on Java and supports plugins.

## How it works
- Create a connection; the navigator lists the databases, schemas, tables, and other objects.
- The SQL editor runs queries and offers auto-complete, formatting, and execution plans.
- The data editor views and edits table rows with filters and charts.
- Data transfer wizards import, export, or migrate tables; ER diagrams show relationships.

## Not for
- NoSQL and some advanced features, which the sources describe as paid-tier only; confirm on the editions page before relying on them.
- Not found: no source compared DBeaver's speed or weight against lighter native GUIs.
