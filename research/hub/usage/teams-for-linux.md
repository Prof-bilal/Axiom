# Teams for Linux

## When to use
- You need Microsoft Teams on a Linux desktop and prefer an app window over a browser tab.
- You want native Linux notifications and a system tray icon.
- You use several Teams accounts and want separate profiles.
- You need screen sharing that works within what the Teams web app allows.

## How it works
- A native Electron app that wraps the Teams web app and adds Linux integration.
- Packaged as AppImage, deb, rpm, snap, tar.gz, Flatpak, AUR and other distro packages.
- Deb and rpm users get updates from the project's own package repositories.
- Unofficial and independent (GPL-3.0); not affiliated with Microsoft.

## Not for
- Teams features the web app itself does not offer. The project cannot add them.
- Environments that need an officially supported Microsoft client.
