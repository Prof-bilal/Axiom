# Inkscape

## When to use
- You need logos, icons or diagrams that must scale without losing quality.
- You want to edit or hand-tune SVG files directly.
- You are drawing shapes with the Pen, Pencil or Calligraphy tools and need precise paths.
- You need to export artwork to several formats from one vector source.

## How it works
- The default file format is SVG, so drawings are stored as editable vector objects.
- Shape tools (rectangles, ellipses, stars, spirals) and path tools (Pen, Pencil, Calligraphy) create objects.
- Objects can be selected, grouped, cloned and stacked; layers and groups organize them.
- Text tools cover typing, fonts and text on a path.
- An export chapter covers saving, exporting and batch export.

## Not for
- Painting or photo-style raster work; use Krita.
- Video or 3D scenes; use Kdenlive or Blender.
