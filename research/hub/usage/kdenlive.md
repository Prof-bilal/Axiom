# Kdenlive

## When to use
- You need to cut, trim and arrange clips on a multi-track timeline.
- You are assembling a video with music, fades, transitions or effects.
- You want to add effects that change over time using keyframes.
- You need to render a finished project to a file such as MP4.

## How it works
- Each project keeps its clips in the Project Bin, where you add clips or folders.
- Drag clips from the Project Bin onto the timeline's video or audio tracks.
- Trim by moving the timeline cursor to a cut point and dragging a clip's edge; clips snap to the cursor.
- Effects are added from the Effects view and adjusted in the Effect Stack; keyframes change values over time.
- Rendering uses the Render dialog (Ctrl+Enter, or Project > Render), where you pick a format and output location.

## Not for
- Recording or live-streaming your screen; use OBS Studio.
- Playing back files without editing; use VLC.
