# Discord

## When to use
- You need a community or team space organised into topic channels rather than a single feed.
- You want text chat and voice channels in the same place for a group that talks often.
- You need roles that control who can see which channels, such as restricting sensitive discussions.
- You want private messages with individuals alongside group servers.

## How it works
- Servers are the top-level communities; each is split into channels for text or voice conversations.
- Roles, set up in server settings, decide which channels each member can open.
- The interface has three areas: the home screen, private messages, and servers.
- New members usually start by reading the announcements and guide channels that explain each channel's purpose and how roles are earned.

## Not for
- Formal, auditable company records or archived decisions: Not found in the sources used; use a documented wiki or ticketing tool.
- Users who must avoid a hosted, account-based chat service: the sources do not describe a self-hosted option (Not found).
