# Jan

## When to use
- You want a ChatGPT-style chat that runs models on your own machine, without sending prompts to a cloud service.
- You are working with private documents or code and want to keep them local.
- You want a desktop app that manages local models for you instead of using the command line.
- You want to expose a local OpenAI-compatible API for other tools on the same machine.

## How it works
- Jan Desktop has chat, model management, MCP connectors, and a local API server, plus a CLI.
- Chat is the main screen; you pick a model and talk to it, with conversations kept locally.
- Models are downloaded and managed inside the app.
- Jan Agent is a separate standalone product for running autonomous coding agents against a local model.

## Not for
- Teams that need shared, centrally managed AI access; a hosted service or self-hosted web UI such as Open WebUI fits better.
- Users who need the largest cloud-hosted models; local hardware limits model size.
