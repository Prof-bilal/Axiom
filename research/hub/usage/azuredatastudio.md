# Azure Data Studio

## When to use
- Only if you already have it installed and must keep working on it until you migrate. It is retired, so do not pick it for new work.
- Migrating an existing workflow: move connections and habits to Visual Studio Code with the SQL extension, which Microsoft names as the replacement.
- Not a choice for new setups; the retirement notice takes effect on 28 February 2026.

## How it works
- Connect to SQL Server, Azure SQL, PostgreSQL, MySQL, or Cosmos DB through server groups that organise saved connections.
- The SQL editor offers IntelliSense, snippets, and results export to CSV, JSON, or XLSX.
- Dashboards and insight widgets show server and database health; extensions add features.
- An integrated terminal runs tools such as sqlcmd alongside the editor.

## Not for
- New database work: Microsoft says to migrate to Visual Studio Code.
- Deep server administration, security configuration, or SSMS-only features such as Query Store and Always On (per the official comparison table).
