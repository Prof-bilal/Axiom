# Zed
## When to use
- You want a fast, native editor for everyday coding in a single window.
- You want AI help built in through the Agent Panel alongside your code.
- You want built-in collaboration with teammates in the editor.
- You prefer a Vim or Helix keymap (vim_mode and helix_mode settings).
## How it works
- Open a folder with `zed <dir>` or Cmd/Ctrl+O.
- The Command Palette (Cmd/Ctrl+Shift+P) reaches every action.
- Settings Editor (Cmd/Ctrl+,) lets you search and change settings directly.
- The Agent Panel (Cmd/Ctrl+Shift+A) starts an AI conversation; Cmd/Ctrl+Enter gives inline assistance.
## Not for
- Work that needs a full JVM or Android toolchain; use IntelliJ IDEA or Android Studio.
- Terminal-only environments over SSH; use Neovim or Helix.
