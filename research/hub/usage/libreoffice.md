# LibreOffice

## When to use
- You need a free, open-source office suite for documents, spreadsheets, and presentations.
- You want a word processor (Writer) for everything from short notes to full-length books.
- You need a spreadsheet (Calc) for analysing data, calculations, and charts.
- You need a diagram or illustration tool (Draw) or a formula editor (Math) alongside your documents.

## How it works
- The suite has six components: Writer (documents), Calc (spreadsheets), Impress (presentations), Draw (diagrams and illustrations), Base (databases with tables, forms, queries, and reports), and Math (formulas).
- Math accepts either a visual formula editor or plain-text input.
- It is developed by volunteers and is free to use, licensed under MPL v2.0.

## Not for
- Not found: the official page does not describe Microsoft Office file format compatibility, so check that before relying on it for .docx or .xlsx exchange.
- Heavy, large-scale database work: Base is a small database manager; use a dedicated server database for that (general guidance; Not found as an official claim).
