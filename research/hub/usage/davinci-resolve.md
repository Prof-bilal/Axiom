# DaVinci Resolve

## When to use
- You edit video and need colour grading, which is Resolve's core strength.
- You want a free professional NLE on Linux, Windows or macOS (the free edition).
- You need Fusion-style compositing or motion graphics in the same app as the edit.

## How it works
- One application with pages for Cut, Edit, Fusion, Color, Fairlight (audio) and Deliver.
- Free edition; DaVinci Resolve Studio is the paid edition with AI features, more Resolve FX, 10-bit/120fps and higher resolutions.
- Linux builds are proprietary and distributed by Blackmagic Design; the official page does not document Linux install steps.
- Needs a capable GPU and driver (community reports cite recent NVIDIA drivers; official requirements were not on the fetched pages).

## Not for
- Machines with weak GPUs or little RAM: the official tech specs were not readable here, so check them before you buy into a workflow.
- Users who need an officially supported Linux install on a non-Ubuntu distribution; Linux installs on newer distributions are community-supported.
