# Emacs
## When to use
- You want a highly extensible, programmable editor configured in Lisp.
- You want one tool for editing, shell work, and many text-based workflows.
- You are comfortable with Emacs keybindings using C- and M- keys.
- You need the terminal build, which is light and runs over SSH.
## How it works
- Work happens in buffers; windows and frames show them.
- Keys use C- (Ctrl) and M- (Meta/Alt) notation, with commands entered in the minibuffer.
- Help is under C-h, and the built-in tutorial is C-h t.
- Opening, saving, and quitting files: Not found in an official page I could read (the GNU site was rate-limited); a third-party guide lists C-x C-f, C-x C-s, and C-x C-c.
## Not for
- Users who want a conventional editor with no learning curve; use VS Code or Zed.
- Users who prefer modal editing; use Neovim or Helix.
