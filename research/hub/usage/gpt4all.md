# GPT4All

## When to use
- You want a desktop chat app that runs open-source models on your own computer with no cloud account.
- You want to chat with your own local documents (LocalDocs) without uploading them.
- You are on Windows, macOS, or Ubuntu and want an installer-based app rather than a server setup.
- You want to try many different open-source models in one place.

## How it works
- It is a desktop application that runs open-source language models locally.
- You pick a model and chat with it in the app; no data is said to leave your machine.
- LocalDocs lets you point the model at local document collections for document chat.
- Full customization of models and settings is offered through the app.

## Not for
- Teams that need a shared, multi-user web interface; Open WebUI fits better.
- Highest-quality answers from large cloud-hosted models; local hardware limits model size.
- Detailed API or server workflows: the official page does not describe an API server, so it is Not found there.
