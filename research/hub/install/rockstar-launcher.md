## Possible errors and fixes

- **Error:** the Lutris installer installs an older launcher build, or the current official launcher fails under Lutris.
  - Cause: the Lutris script installs a legacy version; community posts report failures with the newest build.
  - Fix: Not found. The Lutris page documents no fix and no user comments.
  - Source: https://lutris.net/games/rockstar-games-launcher/
- **Error:** installer script missing for some titles.
  - Cause: the script was removed for those titles (community report on Lutris).
  - Fix: Not found as a reliable documented fix. A manual install is the only route described, with no steps.
  - Source: https://lutris.net/games/rockstar-games-launcher/
