# Archived Omarchy foundation

This directory is historical material from the superseded Omarchy-derived
foundation experiment. It is not an active build input, runtime dependency or
product architecture for Axiom.

The files are retained so the project can inspect previous evidence, licenses,
package assumptions and migration decisions without silently reintroducing
them. New work must follow the reset architecture and [decision 001](../../../docs/decisions/001-remove-omarchy.md).

The ignored `workspace/upstream/` checkouts used by the old wrapper are not
part of this archive and are not required by the repository. They may be
removed from a local checkout after confirming no separate experiment needs
them.
