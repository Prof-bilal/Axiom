## OpenEye (EverEye for Linux) - BEST FIT
- Does: bounded keep-awake sessions (1 min-30 days). Takes a logind `Inhibit` fd (org.freedesktop.login1), optional lid-switch inhibit, UPower battery floor, optional power-saver profile, independent supervisor ("guardian") enforcing the deadline, crash recovery via fd close, JSON CLI (`evereye start 2h30m|status|extend|end|doctor`), tray + dashboard, systemd user unit (Type=dbus, NoNewPrivileges, UMask 0077), private D-Bus integration tests with fake services.
- Maturity: v0.4.0 released; ~2,060 lines C++20 in linux/src+tests (12 cpp, 6 h), tests, CI, AppStream/packaging, 10-distro native matrix, SECURITY.md, a Next.js landing site (landing/). 5 commits in this repo; last 2026-11-08. A -backup copy exists (skipped).
- Stack: C++20, Qt 6 (+DBus), qmake/CMake, systemd user service. License: MIT (linux/LICENSE says "Copyright (c) 2026 Krish Garg", not the owner's name: check authorship/relicense before bundling; Apache-2.0 can include MIT). Source also tracked at a separate repo "Insomnia" (D-Bus name io.github.ProfBilal.Insomnia1; Insomnia/ dir has a Swift Package, i.e. a macOS sibling).
- Interfaces: CLI JSON, user D-Bus service, logind inhibitors.
- Axiom view: (1) Concept + possibly code. Keep-awake is a Settings/Launcher "ActionService" action ("keep awake for 2h"). The inhibit primitive is ~40 lines of D-Bus (logind Inhibit, hold fd). (2) Direct overlap with any planned inhibitor feature; also useful for Jarvis long agent runs (task-scoped, bounded, auto-released "inhibitor lease"; fits the "AI never gets root, bounded, attributable" rules; the bounded-deadline + crash-release design is exactly the pattern Axiom wants). (3) Cost: a second always-on daemon + Qt tray is unjustified inside Axiom (AGENTS.md: every daemon needs justification). Axiom shell is its own; Qt weight is a risk unless the shell is Qt. Reuse logind directly, no extra daemon: the ActionService holds the fd for the session or `systemd-inhibit` as a transient unit. Keep EverEye as a standalone optional Package in the app list. (4) VERDICT: PORT-CONCEPT (design + tests as reference; optionally RECOMMEND-ONLY as a listed external app for users who want the tray). Not BUNDLE.
