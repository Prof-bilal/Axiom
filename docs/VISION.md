# Vision

Axiom is a calm, capable Linux workspace for developers: local-first,
recoverable, understandable and designed around real work rather than desktop
imitation. Its identity comes from a coherent compositor/session, shell,
applications and safe automation boundary that Axiom owns.

The product should make it easy to start a project, find a tool, understand a
system change, keep foreground work responsive and recover an eligible mistake.
AI can propose context-aware workflows, but the desktop remains useful when
models, providers or networks are unavailable. Hardware support, cross-device
continuity and broad distribution claims follow evidence rather than aspiration.

Borrow proven Linux infrastructure and interaction lessons from other systems,
but do not copy another desktop's visual identity, product architecture or
untrusted automation model. Success begins when a developer can boot Axiom in
QEMU, use a real graphical session, and understand exactly which layer owns
each behavior.
