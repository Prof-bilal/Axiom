# Axiom product brief

Axiom is an experimental AI-native Linux desktop for developers, focused on
privacy, secure system agents, recovery and a desktop experience designed from
first principles. It uses standard Linux infrastructure, but the desktop shell,
workflow, applications and product behavior are developed specifically for
Axiom.

The product is organized around a calm graphical workspace: a top panel, dock,
launcher, workspaces, window controls, notifications, control center, lock and
session management, followed by Axiom core applications. AI is an optional,
replaceable platform layer that proposes bounded actions; it is never required
for boot, login, window management, files or terminal use.

The first meaningful milestone is a bootable minimal Axiom graphical session in
QEMU. Hardware coverage, installer, security enforcement, AI workflows and
release support follow separate evidence gates. See [vision](VISION.md),
[architecture](ARCHITECTURE.md) and [phases](PHASES.md).
