# Legacy Phase 1 archiso profile

Status: **historical evidence only**. This profile records the first repeatable
Arch/QEMU boot experiment. It is not the current Axiom desktop base and it must
not be described as an Omarchy, KDE, Hyprland or Axiom Shell implementation.

The profile remains so build/check scripts and retained evidence can be
reproduced while Phase 0 defines a new minimal Axiom base. Its package list and
live services are not a release manifest. Use [BUILD](../../docs/BUILD.md),
[ISO workflow](../../docs/engineering/ISO_BUILD.md) and [phase gates](../../docs/PHASES.md)
for the active direction.
