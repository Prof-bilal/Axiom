# Axiom visual screen assets

These are preview-only raster concepts generated for the Axiom Shell visual
direction. They are not wired into the system image or any UI implementation.

All screen concepts live in this one canonical directory. Existing identity
artwork, wallpaper sources, and mascot assets are not copied here; screens
reference the shared Axiom visual language instead of bundling duplicate
logos, wallpapers, or icons.

The current set follows the Phase 2 Omarchy-derived foundation direction:
Hyprland + Quickshell, dark graphite surfaces, aurora backdrop, teal focus
states, compact panel/dock, keyboard-first interaction, and original Axiom
branding without visible Omarchy product identity.
